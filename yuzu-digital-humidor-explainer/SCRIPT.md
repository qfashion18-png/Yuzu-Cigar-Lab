# Digital Humidor Explainer Script

The production narration is in `narration.txt`.

## Intent

Teach members and demo users how to use the Digital Humidor without requiring them to explore every panel on their own.

## Core Flow

1. Start on Overview for climate, inventory, and alerts.
2. Use demo mode if not signed in.
3. Add cigars with photo, QR, or manual entry.
4. Search and manage inventory from My Cigars.
5. Use Aging Tracker to decide what is ready.
6. Add manual readings or connected hygrometer devices in Alerts and Settings.
7. Watch reorder, allocation, and climate alerts.
8. Log each smoke so quantity and tasting history stay current.
9. Return to the loop: check, add, age, alert, log.

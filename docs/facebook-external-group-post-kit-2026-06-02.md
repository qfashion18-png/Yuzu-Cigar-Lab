# Facebook External Group Post Kit - 2026-06-02

Scope: prepared posts for external Facebook cigar groups and community surfaces. These are admin-review drafts, not live posts. Because several Facebook group rules are not publicly readable without membership approval, ask an admin before posting any branded image or Yuzu mention.

## Operating Guardrails

- Use the logo-badged images only where branded imagery is allowed. If a group rejects branded visuals, use the same post copy with a neutral image or text-only.
- Do not post a link on first contact unless the group rules explicitly allow it.
- Keep copy framed as a question for the group's members, not as a Yuzu announcement.
- Keep every post adult 21+ only.
- Do not include pricing, inventory, checkout, reduced-risk health claims, giveaways, samples, or direct purchase prompts.
- Do not repost the same caption across multiple groups.
